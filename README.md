## Project Overview

The frontend part of the calculator assignment: the web page takes two operands and an operator as input, calls the backend Spring Boot calculation API via `fetch`, and displays the returned result on the page.

## How to Run

This project is a pure frontend page (HTML + CSS + JavaScript) with no dependencies. Simply open `index.html` in a browser.

## Tech Stack

- HTML / CSS / JavaScript
- Native `fetch` calls to the backend RESTful API
