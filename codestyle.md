# Backend Code Style (codestyle)

The backend code in this repository follows the conventions below.

## Naming Conventions

- **Classes / interfaces**: UpperCamelCase (PascalCase), e.g. `CalculatorController`
- **Methods / variables**: lowerCamelCase, e.g. `calculate()`, `firstNumber`
- **Constants**: UPPER_SNAKE_CASE, e.g. `MAX_VALUE`
- **Packages**: all lowercase, e.g. `com.example.calculator`

## Code Style

- Indentation: 4 spaces
- Javadoc comments on every class and public method
- API paths in lowercase, e.g. `/api/calculate`

## Commit Messages

- A short sentence describing the change, e.g. `feat: implement the four basic arithmetic operations`
